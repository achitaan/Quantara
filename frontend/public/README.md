# Current interface assets

`current-fabric.png` is the aqua fabric backdrop for the Current portfolio view. The artwork was generated with ImageGen on October 11, 2026. Portfolio text, navigation, balances, and controls are rendered separately as HTML.

Prompt: recreate the reference's translucent woven aqua fabric on a pale cool white panoramic background, preserving its flowing folds and fine texture, with clean space on the left; remove all text, logos, UI, tables, and charts.

`fonts/current-sans.ttf` is the variable DM Sans font from the [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/dmsans), distributed under the accompanying [SIL Open Font License](fonts/OFL.txt). The image and font are served locally; the interface makes no external requests for either asset.
